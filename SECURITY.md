# Security Policy

## Supported Versions

Currently, only the latest version of OpenLLMTools receives security updates.

| Version | Supported |
|---|---|
| Latest | Yes |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in OpenLLMTools, please report it responsibly.

- Do not publicly disclose unpatched vulnerabilities.
- Use GitHub's private vulnerability reporting feature if available.
- Provide a clear description of the vulnerability.
- Include reproduction steps and relevant technical details where possible.

## Security Considerations

Please take particular care when reporting issues involving:

- API keys and authentication credentials.
- Exposure of sensitive information.
- Unsafe handling of user input.
- External API integrations.
- Potential security weaknesses in application functionality.

## Response

The project maintainer will review submitted reports, assess their severity, and determine appropriate corrective action.

Please allow reasonable time for investigation and resolution before making vulnerability details public.

Thank you for helping keep OpenLLMTools secure.
