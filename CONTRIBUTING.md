# Contributing to OpenLLMTools

Thank you for your interest in contributing to OpenLLMTools!

OpenLLMTools welcomes feedback, bug reports, feature suggestions, and discussions that help improve the project.

## Ways to Contribute

You can contribute by:

- Reporting bugs.
- Suggesting new features.
- Identifying potential improvements.
- Sharing feedback about existing functionality.
- Participating in discussions.

## Issues

Before creating an issue:

1. Check whether a similar issue already exists.
2. Provide a descriptive title.
3. Clearly explain the problem or suggestion.
4. Include relevant information that helps the maintainer understand the issue.

Please keep discussions constructive and relevant to the project.

## Feature Requests

Feature requests are welcome!

When suggesting a feature, explain:

- What the feature should accomplish.
- Why it would be useful.
- How it could improve OpenLLMTools.

Feature requests are suggestions, not guarantees of implementation.

## Code Contributions and Pull Requests

OpenLLMTools currently follows a maintainer-controlled development model.

- Source code modifications are handled exclusively by the project maintainer.
- Contributors should not submit code changes or pull requests unless explicitly invited by the maintainer.
- All official commits and merges are performed by the maintainer.
- The maintainer has final authority over project changes.

This approach helps maintain consistency, code quality, and centralized project management.

## Code of Conduct

Be respectful, constructive, and professional when interacting with other members of the community.

Harassment, abusive behaviour, spam, and deliberately disruptive activity are not welcome.

## Final Note

Every suggestion, bug report, and discussion is appreciated.

Thank you for helping OpenLLMTools grow!
